Entry for make.fun's `bounty-entrants-03` competition, sponsoring three free-to-enter, 72-hour one-line comedy bounties ($5 USDC pool each, split equally $1 × Top 5):

1. **Real-Life Patch Notes: The Comedy Changelog** — https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d
2. **One-Star Review of Something Essential** — https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629
3. **Warning Label for Humans: One Line, Big Laugh** — https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85

`main.ts` validates `BOUNTY.json` and writes it to `$MAKEFUN_OUTPUT_DIR/BOUNTY.json` (default `/output/BOUNTY.json`) using Node 22 standard library only.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
